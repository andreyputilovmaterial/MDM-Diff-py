# Project context (permanent working memory)

Every task in this repository starts and ends with `docs/project-context.md`.

- **Read first.** At the beginning of every task, read `docs/project-context.md`. It
  holds the current architecture, design decisions, review findings, roadmap, and open
  questions for this repository.
- **Update when done.** At the end of every task, update `docs/project-context.md` with
  what changed and what was learned: new findings, decisions and the reasoning behind
  them, and any follow-up items. Do not leave it stale after making code changes.
- **Keep it current.** Treat `docs/project-context.md` as the permanently updated
  context of the current work — the single source of truth that the next task will
  read.
- **Do not link this file from user-facing docs.** It is living working memory and
  changes on every run. READMEs and other stable references should link to stable
  documentation (e.g. `docs/architecture.md`) instead.

Keep the file focused and factual: architecture, decisions + reasoning, findings,
roadmap, open questions. Prefer short bullets over prose.
